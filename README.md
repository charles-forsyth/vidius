# Vidius

A professional CLI for generating videos using Vertex AI VEO models.

## Defaults

If run without flags, `vidius` uses:
*   **Duration**: 8 seconds
*   **Aspect Ratio**: 16:9 (Widescreen)
*   **Audio**: Enabled
*   **Enhance Prompt**: Always Enabled (Required by Veo 3)
*   **Person Generation**: `allow_adult`
*   **Output Directory**: `~/Videos/Vidius` (Configurable in `.env`)
*   **Output File**: Generated from prompt (e.g., `A_cat_eating_pizza.mp4`)

## Usage Examples

### 1. Quick Start
Just provide a prompt. The video saves to `~/Videos/Vidius/`.
```bash
vidius "A cyberpunk city in the rain at night"
```

### 2. Image-to-Video (Start Frame)
Provide an input image to start the video generation.
```bash
vidius "The water begins to flow and birds fly" --image river_start.png
```

### 3. Start & End Frames (Interpolation)
Define both the start and end of the video. The AI interpolates the action between them.
```bash
vidius "A flower blooming in fast motion" --image bud.png --last-image flower.png
```

### 4. Reference Images
Provide images to guide the style or character (up to 3).
```bash
vidius "A knight fighting a dragon" \
  --ref-image character_sheet.png \
  --ref-image style_guide.png
```

### 5. Extend Video
Continue the story from an existing video (must be generated by Veo).
```bash
vidius "The character walks through the door into a bustling market" --extend-video part1.mp4
```

### 6. Vertical Video (Shorts/Reels)
Create a 6-second vertical video.
```bash
vidius "A dancer on stage" -ar 9:16 -d 6
```
*   **Supported Ratios**: `16:9`, `9:16`
*   **Supported Durations**: `4`, `6`, `8`

### 7. Custom Output Filename
Specify a filename to save into the default directory.
```bash
vidius "A quiet beach" -o my_beach_video.mp4
```

### 8. Custom Output Path
Specify a path with a directory separator to override the default directory.
```bash
vidius "A quiet beach" -o ./local_beach.mp4
```

### 9. Raw Generation (Audio Only)
Disable audio for exact control.
```bash
vidius "Abstract geometric shapes" --no-audio
```

### 10. Negative Prompting
Exclude specific elements.
```bash
vidius "A portrait" -np "blurry, distorted, dark, low resolution"
```

## Installation

```bash
uv tool install git+https://github.com/charles-forsyth/vidius
```

## Configuration

Vidius reads configuration from `~/.config/vidius/.env`.
See `envfile.txt` for a template.
